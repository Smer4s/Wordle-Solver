# Wordle Solver

## An AI Model Solution for Game [Wordle](https://www.nytimes.com/games/wordle/index.html)

## How to Run:

### Game:

    cd .\engine\
    uv run main.py

### Tests:

    cd .\engine\src\tests\

#### Feedback tests:

    pytest .\test_feedback.py 

#### Game tests:

    pytest .\test_game.py
